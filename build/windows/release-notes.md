Windows 10/11 x64 · 0.1.5

- Исправлена взаимная блокировка при завершении фонового процесса, способная заморозить сохранение настроек.
- Штатная остановка и переподключение больше не создают ложную ошибку exit status 1. Состояние процесса очищается до повторного запуска.
- После успешного отключения прежняя ошибка убирается. Настоящие аварийные завершения остаются в журнале.
- Убраны повторная проверка сервера после настройки маршрутов и проверка посторонних фиксированных IP для режима исключений. Проверки перед переключением маршрутов и DNS сохранены.
- VPN для всего устройства и раздельное туннелирование сохранены; подключение вручную.

- Меню трея оформлено в темах приложения с Montserrat, статусом, подключением, выбором профиля и настройками.
- Интерфейс запускается с обычными правами, VPN-служба отдельно получает права через UAC. Приложение не перехватывает Print Screen и не привязывает захват к определённой программе. Меню остаётся открытым при захвате.
